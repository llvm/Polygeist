LoopLibrarian ATen pointwise/reduction milestone, 2026-11-11

Completed targeted GPU cases: 49 unique fixtures. This is not a fresh 598-case
coverage census, the paper's 271/598 result, its 28/52 native-library subset,
or the complete 115-case Figure 5 performance comparison.

New pointwise cases: clamp_min_scalar_cpu, clamp_max_scalar_cpu, gelu_cpu_exact,
and hardswish. All 24 full-array checks pass (82,944 outputs), including normal
and special-value inputs, signed-zero policy, input preservation and guards,
host/resident modes, and two scalar parameter settings where applicable.
Actual cuDNN execution is traced; no CPU fallback is counted.
Seven reusable pinned scalar references pass 5,559 upstream-C++/C comparisons
and all 21 Affine/Linalg/tensor validation checks. Four currently match.
These are ATen-source references plus a mechanically constructed cuDNN graph;
EqSat proves application/reference equivalence, not cuDNN implementation
semantics. Generic backend opcode behavior is separately trusted/tested.

New reduction case: prod. Genuine seeded CUB ThreadReduce implementation
specializations supply reusable FP32/FP64 sum and FP32 product references.
All 192 upstream-C++/C comparisons and nine raising validations pass. Separate
DeviceReduce checks pass 240 calls over five sizes, four seeds and four input
modes, preserving inputs and guards. FP32 tolerance is 1e-5+1e-4*abs(reference),
FP64 tolerance is 1e-12+1e-10*abs(reference); NaN class, infinity and zero signs
are checked. Parallel reduction may reassociate: no universal bitwise claim.
Production strict matching proves prod against cub_reduce_product_f32. Its
fresh binary passes all six normal/edge/negative-zero checks in host/resident
modes, with real DeviceReduce traces, inputs and guards intact.

Generic fixes:
- Bounded exact conditional-selection identities prove hardswish without
  reassociation or operation-name recognition. Positive/negative proof tests
  and 122,500 selected special-value combinations pass.
- Preserve negative-zero literals through parsing, structural comparison and
  egglog encoding. Strict nonstructural proofs containing negative-zero atoms
  are conservatively declined. Four focused regressions pass.
- Parse the immutable library text once per exact content, using a bounded LRU.
  Changed contents invalidate it; all provenance/ABI/backend checks still run.
  Full ABI JSON is byte-identical. Fresh-process clamp-min match+verification
  takes 86.127 seconds without reuse versus 6.063 seconds with reuse (14.20x).
  Input, output and semantic-input hashes are identical. This is one measured
  case, not a claim about whole-corpus speedup. Profiles are under
  staged-adapter-cache/.
- Accept canonical rank-option metadata in normalized proofs; malformed,
  unknown or reordered options and changed compiler/cleanup still fail.
  This verifier correction does not change matching semantics.

- sum and sum_cpu_backend: independent row reductions versus one-vector ref;
  generic slicing/layout normalization is needed.

  when lo>hi; no unproved parameter constraint is assumed.
- hardsigmoid and gelu_tanh: strict floating operation-order differences;
  gelu_tanh also has a literal truncation backend gap.
