CUB inclusive-scan production validation, 2026-11-11

44 targeted ATen fixtures are now GPU-validated; cumsum adds one to the earlier 43.
This count measures source-fixture/reference/backend correctness, not aggregate
271/598 paper coverage or equivalence to every public ATen version. Genuine ATen
CUDA comparison of the frozen earlier 43 is a separate report under
issues/aten43_native_cuda_20261111; its version/domain mismatches remain explicit.

The reference specializes the pinned public CUB seeded ThreadScanInclusive
implementation to float/add while retaining extent and seed parameters. It is
raised through the same production recipe as unchanged aten_cumsum.c. Ordinary
strict Linalg matching proves the whole reference/application recurrence,
including the differently ordered outputs. No scan recognizer or formula was
added to the matcher. Typed emission calls actual CUB DeviceScan::InclusiveScanInit.
Its parallel association is validated numerically, not claimed bitwise identical
to the sequential reference for all inputs.

Two generic compiler defects were fixed: raising must combine dependence
classification across all outputs, and debufferization must preserve a repeated
scalar destination as scalar tensor state instead of replicating its initial
value. Scalar projection is guarded by alias and loop-bound checks. Both new
regressions fail before and pass after; all 11 relevant compiler regressions pass.
The reference and application each pass Affine/Linalg/tensor source comparisons
exactly. There are 2,368 independent C++ CUB-body/C-reference scalar checks.

All 6 production GPU checks pass: normal, NaN/infinity edge, signed-zero inputs,
host and resident buffers; 1,536 full outputs plus unchanged inputs and guards.
Finite tolerance is 1e-5+1e-4*abs(reference), matching NaN class/infinity and zero
sign. Traces show real typed CUB calls; no CPU fallback. Independent raw CUB
validation covers 3,072 outputs with four seeds and 12 real calls (max abs 4.77e-7).
