IMPLEMENTATION
lib/polygeist/Passes/NormalizeLinalgMatchingViews.cpp adds an opt-in normalization:
1. Expose projected/broadcast tensor submaps through Linalg indexing maps without
   extending the iteration bounds or losing the output inverse mapping.
2. Use upstream linalg::populateCollapseDimensions for adjacent parallel loops.
   Every operand must use both dimensions consecutively, or use neither.
   Reduction dimensions are not collapsed. Upstream reconstructs linalg.index.
3. Commute reshapes through bounded identity views only when inner extents cover
   the complete base dimensions. Use upstream memref collapse legality to create
   zero-copy descriptor views only for guaranteed collapsible layouts.

Thus A[h,d,k]*x[k] can flatten h,d, while A[h,d,k]*x[h,k] cannot. Padded physical
rows do not get an invalid flat memref view. Unknown dynamic output factors are
conservatively left uncollapsed by this vendored MLIR version.

scripts/correctness/spec_match.py first preserves existing Linalg and generic
region matches, then applies the same normalization to residual application IR
and imported reference IR, and runs the shared Linalg EqSat matcher. Existing
proven launches are temporarily represented by opaque typed calls while MLIR
normalizes; signatures and launches are restored afterward. No semantic body is
invented for those calls. Source parameter names and ABI metadata are preserved
across the MLIR printer. The proof records compiler and normalized-input hashes.

The FP32 SGEMM reference is an ordinary OpenBLAS specialization with M=1,
lda=ldc=1, alpha=1 and beta=0. N,K and the matrix leading dimension remain bound
from application IR. It is raised through the normal import pipeline. The typed
ABI emits cublasSgemm on GPU or cblas_sgemm on CPU. This uses the established
source-reference correspondence between OpenBLAS and cuBLAS, not cuBLAS source.
See generic_solver/lib_v3/manifest/openblas_sgemm.json and the upstream source
hashes there. Import validation passed affine/Linalg/debufferized stages exactly.

scripts/correctness/lib_v2/mlir_lite.py now reads a reshape's result type after
"into" instead of interpreting source and result types as one descriptor.
match_v2.py preserves a collapsed memref's descriptor rather than tracing back
to its higher-rank base. Three parser tests failed before and pass after the fix.

The region matcher's C array-declaration reader now handles scalar typedefs and
type macros, and resolves the reference path from the manifest. This preserves
the leading-dimension relationships when one reference supports multiple
precisions. The previous reader recognized only literal float/double and guessed
the source filename from the routine name; that caused a correlation/covariance
regression when the GEMM reference was generalized. Declaration tests also guard
against mistaking comments, macro array expressions and returns for parameters.

The session build has 16 baseline calls and 22 candidate calls: four added SGEMM
calls and two added copy calls. It has ten SGEMM calls in total. Six existed in
the baseline with the new catalog. Therefore the paired improvement measures the
full normalization, including the two copies, not an isolated Q/K-only ablation.
These call counts are not the paper's 19-operation coverage denominator.

COST / BENEFIT
scripts/correctness/select_measured_candidate.py retains both alternatives and
chooses the normalized one only after correctness and a measured median benefit
larger than the configurable 2% default margin. Profiles must share an input,
hardware, numerical and timing context; IR, proof and executable hashes are
checked. Incorrect, slower, insufficiently beneficial or unmeasured alternatives
do not replace the baseline. The measured ratio here is 0.732630172.

This is an offline measured selection, not a predictive compiler cost model or
a performance guarantee for unmeasured shapes/devices. Normalization remains
opt-in with POLYGEIST_NORMALIZE_PARALLEL_DIMS=1. Selection records and the chosen
IR/proof are saved in selection/; original artifacts remain intact.

  POLYGEIST_NUMERIC_MODEL=relaxed
  POLYGEIST_CUTENSOR_ROOT=/home/arjaiswal/cutensornet-aarch64-root/cutensor

on PYTHONPATH pending the separately tracked standalone import-order correction.

  bash scripts/correctness/build_llama_reproduction.sh OUTPUT_DIRECTORY
Then run this directory's run_gpu_comparison.py after adjusting local/remote
paths for the machine. The script uses the existing protected remote helper;
credentials are not included in this artifact. The captured commands can also
be run directly on the board without that helper.

  python3 issues/llama_rank_collapse_20261111/record_measured_selection.py

    issues/llama_rank_collapse_20261111/baseline-profile.json \
    issues/llama_rank_collapse_20261111/candidate-profile.json \
    --output issues/llama_rank_collapse_20261111/selection
